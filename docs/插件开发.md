# 插件开发指南（支持新游戏）

本工具采用三层插件架构，新增一款游戏的汉化支持只需实现一个 `BasePlugin` 子类并注册。

## 插件接口（最小集）

```python
from ps2hantool.plugins.base import BasePlugin

class MyGamePlugin(BasePlugin):
    name = "mygame"                    # 唯一标识
    display_name = "我的游戏 (SLPM-xxxxx)"

    def detect(self, ctx):
        """返回 dict 表示命中；None 表示不适用。"""
        cnf = (ctx.get("system_cnf") or "").upper()
        if "SLPM_XXXXX" in cnf:        # SYSTEM.CNF 中的引导编号
            return {"name": "游戏名", "slpm": "SLPM-XXXXX", "platform": "PS2"}
        return None

    def extract(self, ctx, progress_cb=None, cancel_event=None):
        """从 ctx['work_dir'] 提取文本，返回 ExtractResult。"""
        from ps2hantool.text.model import ExtractResult, TextFile
        from ps2hantool.text.extractor import SjisRunExtractor
        res = ExtractResult()
        res.detected_game = {"name": "游戏名", "slpm": "SLPM-XXXXX"}
        data = (Path(ctx["work_dir"]) / "DATA.BIN").read_bytes()
        tf = SjisRunExtractor(min_run=4, min_kana=1).extract(data, "DATA.BIN")
        res.files["DATA.BIN"] = tf
        return res

    def writeback(self, ctx, result, progress_cb=None, cancel_event=None):
        """就地回写已翻译条目，返回报告 dict。"""
        # 通用模板：简体→cp932 转换 + 长度适配 + 填充
        from ps2hantool.translate.jp_kanji import to_jis_encodable
        report = {"written": 0, "skipped": 0, "too_long": [], "unmapped_chars": {}}
        # ... 见 ps2hantool/plugins/tm3.py 的 writeback 实现
        return report

    def font_support(self, ctx):
        """返回字库方案说明或 None。"""
        return {"status": "需逆向", "desc": "字库位置与分析结论"}
```

## 注册

编辑 `ps2hantool/plugins/__init__.py`：

```python
from .mygame import MyGamePlugin
def load_builtin_plugins():
    m = get_manager()
    if not m.all():
        m.register(TM3Plugin())
        m.register(TM2DatPlugin())
        m.register(MyGamePlugin())       # ← 新增
        m.register(GenericSjisPlugin())
    return m
```

## 提取器参数参考（`SjisRunExtractor`）

| 参数 | 默认 | 用途 |
|---|---|---|
| `min_run` | 4 | 最少字符数 |
| `min_kana` | 1 | 最少假名数（1=宽松，2=严格） |
| `min_semantic` | 2 | 最少假名+汉字数 |
| `rare_filter` | True | 生僻字过滤（**仅压缩流扫描开启**；未压缩文本会误杀真实文本） |
| `drop_dups` | True | 按原文去重 |

## 回写要点

1. **编码**：游戏内文本先 `to_jis_encodable()`（OpenCC 简转繁 + 词表 + '・' 兜底），保证 cp932 可编码；
2. **长度**：中文一般比日文短 → 短了用空格填充（`0x20`），注意保留尾部换行（TM3 是 `0x0D`）位置；
3. **超长**：无法回写的条目进 `too_long` 报告，提示人工处理；
4. **备份**：`pipeline.writeback()` 会自动备份被修改文件，出错可恢复。

## 字库插件

实现 `FontInjector`（`ps2hantool/font/bitmap.py`）：`analyze()` 解析游戏字库格式，
`inject()` 写入新字库并修正映射。可用 `BitmapFont.generate(size=16)` 生成点阵字库，
用 TiledGGD 等工具可视化游戏贴图辅助逆向。无法完整注入时返回 `degrade_plan()` 降级方案。
