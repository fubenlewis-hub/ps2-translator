# 故障排查指南

## 一、安装与环境

**Q: 启动 GUI 报 `ModuleNotFoundError: PySide6`**
A: 未安装依赖：`pip install -r requirements.txt`；若在虚拟环境外运行请先激活。

**Q: `pycdlib` 打开 ISO 报错**
A: 确认文件为标准 ISO9660 镜像（PS2 通常就是）；`.cue/.bin` 需先用工具转为 `.iso`；
   破损镜像请用 Redump 校验（`Get-Filehash <file> -Algorithm SHA1`）。

## 二、载入与识别

**Q: 载入很慢 / 磁盘空间不足**
A: 整盘提取需要与 ISO 等量的磁盘空间（TM3 约 4.7GB）。工作目录位于 `工程目录/work/`，
   可在选择工程时放到空间充足的磁盘。

**Q: 检测不到游戏（提示用通用插件）**
A: 通用插件会全盘扫描，仍可提取大部分文本；或按 `docs/调研报告.md` 的格式为你的游戏写插件。

## 三、提取结果

**Q: 提取到的文本混入乱码**
A: 启发式扫描的固有噪声：提升阈值可减少误报（`SjisRunExtractor(min_run, min_kana)`）；
   校对页可手动删除；导出 CSV 离线清洗后导回。

**Q: 提取的部分对话缺失**
A: 缺失部分多在 DATA1/DATA2/DATA4.BIN 的 ATP 压缩条目中（解压为实验功能，成功率有限）。
   主对话与菜单（DATA5.BIN + ELF + DATA3.BIN 未压缩条目）已覆盖。

## 四、翻译

**Q: 测试连接失败**
A: 检查 Base URL（OpenAI 格式必须以 `/v1` 结尾）、Key 是否有效、模型名是否可用；
   本地服务请确认已启动且监听端口正确（Ollama `11434`、LM Studio `1234`）；
   网络代理环境请为本工具配置系统代理。

**Q: 翻译报 429 / rate limit**
A: 在设置中调低「每分钟请求上限」（如 10~20）与「并发数」（如 2），稍后重试；
   工具已内置指数退避重试（3 次）。

**Q: 翻译中断了**
A: 直接重新运行翻译，已译条目会自动跳过（结果保存在 `data/translated.json`）。

**Q: 译文不符合术语表**
A: 术语表条目必须与原文完全一致（含标点全半角）。确认后重新翻译未译条目即可。

## 五、回写与打包

**Q: 回写报告里有 too_long 条目**
A: 中文一般比日文短，超长多出现在原文极短（如 <4 字符）或含占位符的条目。
   处理：校对页手动缩短译文，或保持原文（跳过）。

**Q: 打包后 ISO 在 PCSX2 里黑屏/无法启动**
A: 先确认 `SYSTEM.CNF` 与引导 ELF 未被修改（工具不会改它们）；再确认磁盘空间足够；
   若修改过 ELF（如 TM3 插件提取系统文本后回写），可「恢复备份」后仅回写 DATA5.BIN 验证。

**Q: 如何恢复原版文件**
A: `工程目录/backup/<时间戳>/` 中保存回写前的文件副本；
   CLI：`python cli.py writeback` 前确认，或手动从 backup 复制回 `work/`。

## 六、字库与显示

**Q: 游戏内中文显示为方块/空白**
A: 字库注入未完成（见使用说明「关于字库」）。当前已交付：点阵字库文件生成 + 注入框架 +
   降级方案文档。验收文本流程时可先确认"文本回写正确"（可在 PCSX2 中观察日文是否变成了中文编码的乱码，
   说明回写成功、仅缺字库渲染）。

**Q: 部分汉字显示为同音字**
A: 这是降级策略（未收录字用同音字/常用字代替），报告中会列出替换清单。

## 七、程序闪退 / 崩溃

**Q: 载入 ISO 时程序直接闪退（无任何错误提示）**
A: exe 为窗口模式，崩溃前通常不留界面信息。请按顺序排查：

1. **确认使用最新 exe**：早期版本存在"工作线程跨线程操作界面控件"导致的 Qt fatal 闪退
   （症状：提取到约 1/7 时进程消失、磁盘空间充足）。`dist/PS2汉化工具.exe` 已修复：
   日志改走线程安全信号队列 + 全局崩溃日志。
2. **查看崩溃日志**：exe 同目录下若生成了 `crash.log`（Python 异常回溯）、`app.log`、
   或 `selftest.txt`，请把内容发给我。
3. **查看 Windows 事件查看器**：Win+R → `eventvwr` → Windows 日志 → 应用程序 →
   按时间找 `应用程序错误`，展开看 **故障模块（faulting module）**：
   - 若是 `Qt6Core.dll` / `Qt6Widgets.dll` → Qt 层崩溃（通常与跨线程操作或显示驱动相关）
   - 若是 `PS2汉化工具.exe` 且异常代码 `0xc0000409`（fail fast）→ 程序断言/abort
4. **自检**：运行 `PS2汉化工具.exe --selftest`，把生成的 `selftest.txt` 发我；
   运行 `PS2汉化工具.exe --loadcheck <iso路径>` 可无头复测载入（结果写入 `loadcheck.txt`）。
5. **排除法**：把 exe 复制到纯英文路径（如 `C:\Tools\`）再试，排除中文路径/权限因素；
   杀毒软件若拦截，请添加信任（PyInstaller 单文件常见误报）。

**Q: 载入提示"任务失败"（有弹窗）而不是闪退**
A: 属于可捕获的业务异常，日志页有详情；常见于磁盘空间不足（需要与 ISO 等大的可用空间）、
   ISO 损坏（用 Redump 校验）、或文件被占用。查看 `工程目录/logs/run.log`。

## 八、其他

**Q: 术语一致性报告说有残留日文**
A: 说明翻译时模型未按术语表输出或术语表覆盖不全；在术语管理页补充后重新统一（`cli.py unify`）。

**Q: 软件被杀毒软件误报**
A: 开源项目常见情况；从本仓库源码运行即可，或添加信任。
