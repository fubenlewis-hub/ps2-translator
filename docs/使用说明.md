# 使用说明

## 安装

```bash
# Windows / macOS / Linux 通用
python -m venv venv
venv\Scripts\activate          # Windows；macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

依赖：`PySide6`、`pycdlib`、`pillow`、`requests`（均为常见开源库）。

## 分步操作指南

> **软件状态机**：界面底部状态栏 + 首页顶部状态横幅实时显示当前阶段
> （空闲 → 载入中 → 已载入 → 提取中 → 已提取 → 翻译中 → 已翻译 → 回写中/打包中 → 完成/出错），
> 任何耗时操作都在后台线程执行，界面不卡死；失败会自动进入"出错"状态并在日志页给出原因。

### 1. 载入 ISO
- 点击「浏览…」选择 PS2 游戏 ISO（`.iso`；`.bin/.cue` 请先转为标准 ISO）。
- 点击「载入并检测游戏」：工具会整盘提取到工程目录（4.7GB 的光盘约需 1~3 分钟），
  并依据 `SYSTEM.CNF` 中的编号自动识别游戏、加载对应插件。

### 2. 提取文本
- 首页点「① 提取文本」，或进入「2 提取结果」查看：文本总条数、总字符数、分类统计、检测到的游戏名、术语表预览。
- 注意事项：
  - 提取是启发式的：对话/菜单文本按 Shift-JIS 可读运行扫描，可能混入少量噪声；
  - 若某类文本缺失，可用「通用扫描」插件强制重提（需在 CLI 指定 `--plugin generic_sjis` 或在源码注册）。

### 3. 术语表
- 「3 术语管理」页可增删改查；内置常用游戏名词预设（角色/学校等）。
- 「联网搜索更新」：对自动检测到的说话人名检索 维基百科（含日文条目→中文官方译名的跨语言链接）/萌娘百科/Bing，
  结果以表格弹出，**勾选后一键采纳**（联网失败会自动降级提示，不影响使用）。
- 「AI 抽取术语」：把游戏文本交给已配置的翻译引擎，自动抽取专有名词并建议中文译名
  （借鉴开源项目 [KeywordGacha](https://github.com/hang333/KeywordGacha) 的思路），同样弹窗勾选采纳。
- 术语表保存在 `工程目录/data/glossary.json`，可导出 CSV 交给校对者，再导入合并。

### 4. 翻译设置
- 云端：OpenAI 兼容（`https://api.openai.com/v1`）或 Anthropic（`https://api.anthropic.com/v1`）。
- 本地：Ollama / LM Studio / llama.cpp-server / text-generation-webui 的 OpenAI 兼容端点。
- 先「测试连接」再保存；`rpm`（每分钟请求数）与「并发数」请按服务商限制设置，避免 429。
- 可点「**保存并开始翻译**」跳过手动步骤直接进入翻译。

### 5. 开始翻译 / 校对
- 首页「④ 开始翻译」（或上一步的"保存并开始翻译"）：读取已保存的引擎配置，后台批量翻译，
  状态栏实时显示进度；完成后自动跳到「5 文本校对」。
- 校对页原文/译文对照表可直接编辑；导出 JSON/CSV/XLIFF 可离线校对后导入。
- 若批量翻译中断，重新运行翻译会**自动跳过已译条目**（断点续传）。

### 6. 汉化与打包
- 首页「一键全流程」或分步：翻译 → 术语统一 → 回写 → 字库 → 打包。
- 回写前自动备份（`工程目录/backup/<时间戳>/`），出错可恢复。
- 输出：`工程目录/output/hanyihua_<编号>.iso`，原 ISO 不被修改。

### 7. 在 PCSX2 中测试
1. 打开 PCSX2 → CDVD → ISO 选择器 → 选择汉化 ISO；
2. 建议开启「快速启动」直接进游戏；
3. 若中文显示为方块/乱码，属于字库注入未完成（见下文），可先验收已回写的文本流程。

## 关于字库（重要说明）

PS2 游戏字库格式各异，完整注入需要针对具体游戏逆向其字形布局与码点映射。当前版本：
- 已实现：点阵字库生成（`data/font_16px.bin` + `font_16px.json`，可用 `python cli.py font <工程> --size 16`）；
- 已提供：注入框架与降级方案（字模替换 / 同音字 / 文本预替换），见 `docs/调研报告.md` 风险节；
- 未实现：TM3 字库容器（DATA2/DATA4.BIN）的自动替换 —— 这属于后续逆向工作项。

## 常见问题（快速指引）

| 现象 | 处理 |
|---|---|
| 提示"未能识别游戏" | 检查 SYSTEM.CNF 是否完整；可强制用通用插件（CLI `--plugin generic_sjis`） |
| 翻译请求 429/超时 | 调低 `rpm` 与并发数，或在设置里更换模型 |
| 译文没有遵守术语表 | 术语表条目需与原文**逐字一致**（含全角/半角）；确认后再翻译 |
| 回写后游戏乱码 | 先「恢复备份」；确认文本编码为 cp932 可编码；对照日志中的超长条目 |
| 汉化 ISO 无法启动 | 确认 SYSTEM.CNF 未被改动；尝试在 PCSX2 中关掉快速启动 |
